Is k-means dead?

Meta says its new e-means finds groups just as good as k-means in about a tenth of the time. Test the claim yourself with three experiments that run on your device.

k-means · 195725

Goes through all the data, moves every centre once, repeats. 25 reads.

e-means · 2026~3

Learns from small handfuls, nudging the centres after each. ~3 reads.

Two terms used on this page
One readGoing through every data point once. Fewer reads means less work.
Grouping errorHow far, on average, each point sits from the centre of its group. Lower means tighter, better groups.
A fair testBoth run at the same time, from the same random centres, with the same distance code. Any gap comes from the algorithm.

How we kept this a fair test
  • Both run at the same time, each on its own CPU core, with exactly the same distance code.
  • Both start from the same random centres and are scored the same way, on every point, after the clock stops.
  • e-means is a line-by-line JavaScript copy of Meta's own code (faiss 1.16) and picks the same settings theirs does.
  • Times depend on your device. Each run starts from new random centres, so results vary slightly. Meta's code does the same.
